# Frontend Beta Status

Asthra frontend is beta-ready for platform navigation demos and basic module browsing.

## Ready

- Protected shell
- Auth pages
- Workspace/project context
- Grouped navigation
- Collapsible desktop sidebar
- Command palette
- Home dashboard
- Global search UI
- Assistant panel
- Settings foundation
- MVP module screens for all current major services

## Partially Ready

- Create/edit flows exist only where already implemented in earlier MVP screens.
- Assistant and search depend on backend availability and indexed content.
- Module status and recent activity cards use placeholders.
- Settings preferences are not persisted beyond existing shell stores.

## Not Ready

- Production preference storage
- Realtime collaboration
- Advanced analytics and charts
- File uploads
- Agents and automation execution UI
- Production-grade RAG UX

## Current Test Scope

Tests use mocked APIs and cover shell, navigation, command palette, home, assistant, search, settings, shared states, and module pages.
