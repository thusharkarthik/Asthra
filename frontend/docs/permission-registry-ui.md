# Permission Registry UI

Access Control includes two Phase A tabs.

## Permission Registry

Shows the baseline registry by module and resource.

The tab displays:

- expected permissions
- resource
- action
- scope
- risk
- existing/missing status
- missing or inactive count

## Permission Gaps

Shows classification results:

- missing permissions
- malformed permissions
- unmapped permissions
- broad permissions

Statuses are shown as text badges:

- existing
- missing
- deprecated
- broad
- custom
- system

## Role Mapping Insights

The Role Mapping tab shows:

- total permission count
- high-risk permission count
- unmapped permission count
- broad manage permission count
- module distribution

Phase A does not auto-change role mappings.

## Permission Filters

The Permissions tab filters by:

- module
- resource
- action
- scope
- risk
- source
- status
