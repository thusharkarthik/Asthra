# Admin Setup Workflow

1. Register or sign in.
2. Open `Settings`.
3. Create an organization from `Settings > Organizations`.
4. Create a workspace from `Settings > Workspaces`.
5. Create a project from `Settings > Projects`.
6. Confirm the header selectors show the new organization, workspace, and project.
7. Open `Flow`.
8. Create a work item for the selected project.
9. Return to settings to review members, teams, roles, permissions, and API keys.

This workflow uses existing core-service APIs through the API Gateway. No non-core backend services are changed by the settings foundation.
