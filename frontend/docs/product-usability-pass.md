# Frontend Product Usability Pass

## What Changed

- Shared setup guidance now explains organization, workspace, and project prerequisites.
- Create dialogs have a reusable structure for labels, validation, cancel actions, loading states, and error display.
- Toast feedback is available at the app level.
- Detail pages have a reusable layout for overview, metadata, activity, linked entities, and danger-zone placeholders.
- `/platform/crud-checklist` gives internal testers a module-by-module readiness view.

## Screens Affected

- Home
- Flow
- Docs
- Discover
- Desk
- Pulse
- Dev
- Collab
- Automation
- Connect
- Guard
- Insights
- Media

## Remaining Gaps

- Not every module has full edit/delete UI yet.
- Some modules still use list-first MVP screens.
- Toast adoption should expand to every mutation after manual CRUD testing.
- Breadcrumbs and action menus should be added once route structure stabilizes.
