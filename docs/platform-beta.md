# Platform Beta

Asthra platform beta focuses on internal alpha demonstrations of one connected workspace.

## Included

- Unified frontend activity feed foundation
- In-app notification center foundation
- Cross-module entity link rendering
- Recently viewed and recently modified item foundations
- Favorites foundation for work items, docs pages, dashboards, and projects
- Workspace dashboard summary cards
- Global search result navigation with source and entity badges
- Workspace settings placeholders for General, Members, Projects, Integrations, AI Preferences, and Notifications

## Not Included

- Agents
- Realtime delivery
- Cache layer
- Production vector database or production RAG changes
- New backend APIs

## Demo Flow

1. Sign in.
2. Select workspace and project context.
3. Review Home dashboard summary cards.
4. Open Global Activity Feed.
5. Open Notifications from the top bar.
6. Review Favorites, Recently Viewed, and Recently Modified.
7. Use Global Search and navigate to a result.
8. Review Cross-Module Links.
9. Open Workspace Settings sections.

The current implementation uses frontend contracts and mock-backed aggregation where backend aggregation APIs are not ready.
