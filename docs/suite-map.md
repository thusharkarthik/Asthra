# Asthra Suite Map

Asthra is organized as a suite of related platform areas.

| Suite Area | Service Boundary | Direction |
| --- | --- | --- |
| Asthra Core | `services/core-service` | Foundation platform, identity-adjacent records, organizations, workspaces, roles, projects, and activity logs. |
| Asthra Flow | `services/flow-service` | Work management workflows. |
| Asthra Docs | `services/docs-service` | Knowledge and documentation. |
| Asthra Discover | `services/discover-service` | Product discovery and innovation. |
| Asthra Desk | `services/desk-service` | Service management. |
| Asthra Dev | `services/dev-service` | Engineering and DevOps workflows. |
| Asthra Pulse | `services/pulse-service` | Incident and reliability workflows. |
| Asthra Intelligence | `services/ai-service` | Future AI layer. |
| Asthra Automate | `services/automation-service` | Future automation and agentic workflows. |
| Asthra Insights | `services/insights-service` | Analytics and reporting. |
| Asthra Connect | `services/connect-service` | Integrations. |
| Asthra Guard | `services/guard-service` | Security and governance. |
| Asthra Memory | `services/memory-service` | Future AI memory and context. |
| Asthra Collab | `services/collab-service` | Collaboration. |
| Asthra Media | `services/media-service` | Future multimodal capabilities. |

These service boundaries are placeholders at this tier. Implementation begins with Asthra Core only when Level 2 starts.
