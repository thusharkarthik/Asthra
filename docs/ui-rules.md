# UI Rules

## Scope

Every page supports:

- Organization Scope
- Workspace Scope
- Project Scope

## Lists

Every list supports the workflow-appropriate form of:

- Search
- Filter
- Sort

## Actions

Every action supports:

- Permission checks
- Loading state
- Success feedback
- Error feedback

## Page States

Every page supports:

- Loading state
- Empty state
- Error state

## Labels

Use names, titles, and readable labels as primary UI. Avoid raw IDs as primary labels unless no readable value exists.

## Navigation

Use breadcrumbs and contextual back links on detail pages and nested workflows.
