## Core navigation baseline audit

Created `.asthra/reports/CORE_NAVIGATION_BASELINE.md` as the Step 1 sidebar/navigation baseline before rebuilding Navigation Registry customization.

Findings:
- Sidebar source order is Core Navigation Registry from `/context/platform`, then Module Registry-derived navigation, then static fallback constants.
- Platform, Organization, and Work modes are selected in `AsthraShell` from current user/roles, route auto-detection, Superuser override, and God Mode simulation mode.
- Sidebar item visibility uses backend permission codes through `can(...)`; normal visibility does not authorize by role name.
- God Mode and bottom dock behavior are separate from navigation customization and must be preserved.
- Navigation Registry v1 already exists in Core and `/context/platform` already returns `navigation`.
- No active `core.navigation_config.enabled` flag or Role Navigation Config implementation exists yet.
