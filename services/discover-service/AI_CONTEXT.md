# Discover Service Context

## Purpose

Convert opportunities into executable work.

## Owned Data

- Ideas
- Feature Requests
- Feedback
- Validation
- Prioritization
- Roadmaps

## Not Owned Data

- Users
- Docs pages
- Flow work items
- Releases
- Tickets
- Incidents

## APIs

- Idea CRUD
- Feature request CRUD
- Feedback CRUD
- Validation workflow
- Roadmap views

## Events Published

- IdeaCreated
- IdeaValidated
- IdeaConvertedToWork
- RoadmapItemCreated

## Events Consumed

- Future Docs specification events
- Future Flow work completion events

## RBAC Rules

- Use Discover permission codes such as `discover.idea.create`, `discover.idea.edit`, and `discover.idea.manage`.
- Resolve identity, membership, and scope through Core.
