# Asthra API Client

`packages/api-client` contains lightweight Python API clients for Asthra services.

The package is intended for future internal tooling, scripts, tests, and service-to-service experiments. It is not wired into existing services yet.

## Included Clients

- `CoreClient`
- `FlowClient`
- `DocsClient`
- `AIClient`
- `MemoryClient`

## Test

```bash
python -m pytest tests -q
```
